# Bollywood Draw It

Bollywood Pictionary for parties. Two teams or solo, with Movies, Songs and Characters word packs and a sketch pad for iPad and Apple Pencil.

Plain HTML, CSS and JavaScript. No build step. It has a manifest and a service worker, so it can be added to the Home Screen and played offline.

Live site: https://Ari070499.github.io/bollywood-draw-it/
